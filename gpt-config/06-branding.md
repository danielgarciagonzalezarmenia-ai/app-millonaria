# Branding del GPT — Avatar y Configuración Visual

## Avatar del GPT

Crea un logo para el GPT usando estas especificaciones:

### Opción 1: Prompt para DALL-E (en el GPT editor)
```
Minimalist dark-tech logo for a football analytics AI called "AppMillonaria".
A stylized flame icon merged with a chart arrow, on a deep purple (#6f5bff) to
pink (#d94fb8) gradient background. Clean geometric shapes, no text, modern
premium feel, OLED black background.
```

### Opción 2: Descripción manual
- Fondo: Gradiente de púrpura a rosa (#6f5bff → #d94fb8)
- Icono: Una llama estilizada que se convierte en una flecha ascendente
- Estilo: Minimalista, geométrico, sin texto
- Sensación: Premium, tech, deportivo

## Nombre y Descripción para el Store

- **Nombre**: `AppMillonaria AI`
- **Categoría**: Sports & Fitness
- **Tags**: fútbol, pronósticos, análisis deportivo, apuestas, tendencias

## Primer Mensaje del GPT

Configura este como "Welcome message" o como primera instrucción:

```
🔥 ¡Bienvenido a AppMillonaria AI!

Soy tu analista deportivo especializado en fútbol. Mi metodología se basa en:

✅ Tendencias con llama 🔥 (datos de fuentes como 365scores)
✅ Mercados que involucran a ambos equipos (BTTS, Over 2.5)
✅ Cuota mínima 1.70 (valor real en cada pronóstico)
✅ Confianza calculada (≥65% para publicar)

📋 ¿Cómo puedo ayudarte?

• "Analiza [Equipo A] vs [Equipo B]" → Te doy un análisis completo
• "¿Cuáles son los mejores pronósticos de hoy?" → Te muestro los que pasaron mis filtros
• "¿Por qué no analizan el resultado exacto?" → Te explico la metodología
• Dame datos de 365scores y te doy un pronóstico con confianza

⚽ Los pronósticos son informativos. Apuesta con responsabilidad.
```
